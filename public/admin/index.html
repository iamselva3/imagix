CLOUDFLARE & R2 INFRASTRUCTURE

Storage & API Credentials Engine

Edit your Cloudflare R2 bucket, API credentials, and studio security. Saving here updates your .dev.vars environment variables instantly.

1. Cloudflare R2 Object Storage (Photos & Thumbnails)

Used to store full-resolution photographs, WebP thumbnails, and transparent hero cutouts. Deleting any photo from the library purges it directly from this bucket.

Default: imagix-photography-images
Found on Cloudflare dashboard right sidebar
From: Cloudflare Dashboard → R2 → Manage R2 API Tokens
S3 Secret Key generated when creating R2 API Token
If you connected a custom domain to your R2 bucket in Cloudflare

2. Cloudflare KV Database & Deployment Tokens

Key-Value storage for photo metadata indices, CMS text content, and contact submissions.

Create via: npx wrangler kv namespace create IMAGIX_META
For automated terminal or GitHub Actions deployments

3. Studio Security & Access Credentials

Credentials required to authenticate into this Admin CMS portal.

The password you enter on the login screen
Used to cryptographically sign session tokens
For WhatsApp floating button & direct bookings

📖 Quick Reference: Where to find each credential in Cloudflare

1. Cloudflare Account ID: Log into dash.cloudflare.com. Look at the right sidebar under Account ID. It is a 32-character hex code.
2. R2 Bucket Name: Go to Cloudflare Dashboard → Storage & Databases → R2. Click Create Bucket and name it imagix-photography-images.
3. R2 Access Key & Secret Key: In the R2 tab, click Manage R2 API Tokens on the right. Click Create API Token with Object Read & Write permission. It will generate an Access Key ID and Secret Access Key.
4. KV Namespace ID: Run npx wrangler kv namespace create IMAGIX_META in your terminal. Paste the returned id into the field above.
5. Instant Deletion: When configured, any photograph deleted in the Photo Library tab is immediately purged from Cloudflare R2 storage without leaving orphaned files.
